# ConfiNuvem

Repositório do plano de negócios e de marketing da ConfiNuvem, desenvolvido para a disciplina de Empreendedorismo do curso de Análise e Desenvolvimento de Sistemas do IFPB, Campus Esperança.

Slogan: "Confiança na nuvem".

## Sobre o repositório

Este repositório não contém código. Ele reúne apenas documentação em Markdown: o plano de negócios, o plano de marketing e os materiais de apoio que os acompanham. O objetivo é manter tudo versionado, fácil de revisar e simples de editar em equipe.

## Estrutura

```
.
├── imagens/                                 # imagens usadas nos documentos (logo, diagramas)
├── diagrama-modelo-de-negocios.md           # diagrama do modelo de negócios
├── plano-de-marketing.md                    # plano de marketing (seção 3 do plano de negócios)
├── plano-de-negocios.md                     # plano de negócios
├── protocolo-de-migracao-e-atividades-chave.md  # protocolo de migração e atividades-chave
├── rascunho-plano-de-negocios.md            # rascunho do plano de negócios
├── AGENTS.md                                # instruções para agentes de IA e regras de trabalho
└── README.md
```

## Como usar

Não há instalação, build ou execução. Os arquivos são lidos e editados diretamente em qualquer editor de texto, e o GitHub renderiza o Markdown na própria página do repositório.
